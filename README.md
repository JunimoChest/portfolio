# 创意作品集

游戏广告创意策划、平面设计与视频制作、AI 创作与互动作品的单页作品集。

## 本地预览

直接双击打开 `index.html` 即可。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库，例如 `portfolio`
2. 把本文件夹内容上传到仓库根目录
3. 进入仓库 `Settings` → `Pages`，Source 选择 `main` 分支的根目录
4. 访问 `https://你的用户名.github.io/portfolio/`

网页图片已压缩到 `web/assets/`，视频已压缩到 `web/videos/`，原始大文件不会进入仓库。
